# Product Overview

## Users
- **Campus customers** (students, faculty) who want a quick, healthy evening meal.
- **Founders (Bhawna and Ruchika)** who run orders and operations during 4:00 PM to 8:00 PM.

## Goals
| Goal | How it is measured |
|---|---|
| Remove repeat phone calls for ordering | Share of orders placed through the app |
| Grow evening order volume | Orders per month (500 in the first month measured) |
| Help customers choose healthy items | Nutrition shown on every menu item |

## User stories and acceptance criteria

**1. Browse the menu**
As a customer, I want to see all items with prices so that I can decide what to order.
- All items are grouped by category and show name and price.
- The page works on a mobile screen.

**2. See nutrition**
As a health-conscious customer, I want calories and protein for each item so that I can pick meals that fit my goals.
- Each item shows calories, protein, carbohydrates, fat and fibre per serving.
- Values are labelled approximate.

**3. Place an order**
As a customer, I want to order without calling so that I save time.
- I can add items to an order and submit it.
- The founders receive the order details.

**4. Repeat an order**
As a returning customer, I want to reorder quickly so that I do not repeat the same steps.
- A previous order can be placed again with minimal input.

**5. Know when and how to reach the founders**
As a customer, I want to see service hours and contact details so that I know when I can order.
- 4:00 PM to 8:00 PM is shown in the header and footer.
- The phone number is tappable on mobile.

## Out of scope (current version)
Online payments, delivery tracking and loyalty features.

## Possible next steps
- Order analytics (top items, peak hours) to plan stock
- Pre-orders for the 4:00 PM slot
- Feedback collection after each order
